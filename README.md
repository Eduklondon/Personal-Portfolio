## Preview local da tela de Login

Abra o arquivo `index.html` diretamente no navegador.

Ou sirva via um servidor local (recomendado):

```bash
# usando Python 3
cd /workspace
python3 -m http.server 5173
# Abra: http://localhost:5173
```

Estrutura criada:
- `index.html`: marcação da tela de login
- `styles.css`: estilos responsivos e tema escuro profissional
- `script.js`: interações (validação, toggle de senha, lembrar-me)
